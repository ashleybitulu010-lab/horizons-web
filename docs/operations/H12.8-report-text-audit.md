## 1. Current report text detection

| Layer | Mechanism | Phrases covered |
|-------|-----------|-----------------|
| Frontend `chatRouter` | `isPdfReportRequest` → n8n first | PDF + bilan/rapport context |
| Frontend migrated reads | H12.1–H12.6 per-capability flags | Sales, Expenses, Stock, Products, Debts, Profit |
| Frontend global read | `isReadIntent` + `VITE_ASHY_READ_CHAT` | Generic read incl. `/bilan/` — **OFF in prod** |
| Backend V2 classifier | `isGeneralActivitySummaryQuery()` | « Comment vont mes finances », « Fais-moi le point », « Donne-moi un résumé » |
| Backend legacy orchestrator | `regex-resolver` → `generate_report` | « Je peux avoir mon bilan », « Fais-moi un bilan » |
| n8n prep agent | `recherche` vs `synthese_pdf` | Text bilan → recherche ; PDF explicite → synthese_pdf |

**Gap:** Plain report phrases (« Fais-moi un rapport », « Fais-moi un bilan ») → **n8n** in production (no REPORT flag, PROFIT patterns don't cover them).

## 2. PDF detection (must stay prior)

| Function | Location | Rule |
|----------|----------|------|
| `isPdfReportRequest` | `chatRouter.js` | PDF cue AND bilan/rapport context |
| `isPdfReportRequest` | `regex-resolver.js` | Same + `génère` cue (backend) |
| n8n prep | `_prep_agent_new.js` | export/PDF cue + bilan/rapport → `synthese_pdf` |

**H12.8 enhancement:** extend frontend PDF guard so standalone PDF requests (`Envoie-moi le PDF`, `Génère le PDF de mon activité`) route n8n **before** REPORT.

## 3. Report vs PDF separation

```
PDF guard (isPdfReportRequest)     → n8n  [ALWAYS FIRST]
WRITE guards                       → n8n or ashy write
Sales / Expenses / Stock / Products / Debts / Profit  → V2 if migrated
Report (NEW H12.8)                 → V2 if VITE_ASHY_READ_REPORT=true
Global read / default              → n8n
```

Report text must **exclude** `\bpdf\b` in `isReportReadIntent`.
