## 4. Financial definitions (immutable — source: financial-metrics.js)

| Metric | Definition |
|--------|------------|
| REVENUE | `totalRevenue` from sales summary |
| COLLECTED | `totalCollected` = Σ montant_paye |
| EXPENSES | `totalAmount` / `totalExpenses` |
| **PROFIT** | `round2(totalCollected - totalExpenses)` — **cash-basis** |
| MARGIN | profit / revenue × 100 |
| EXPENSE RATIO | expenses / revenue × 100 |
| COMPARISON | current/previous, absoluteChange, percentageChange, direction, percentageReason |
| previous = 0 | percentageChange = null, reason NO_BASELINE |

Outstanding receivables (reste_a_payer) are **not** counted as collected cash.
