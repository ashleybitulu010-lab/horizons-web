## 4. Legacy Path (before)

```
User message (sales read)
  → chatRouter: VITE_ASHY_READ_CHAT=false → N8N
  → POST /hcgi/api/chat
  → n8n Ash Ledger Bot
  → Supabase ventes SELECT
```

---

## 5. V2 Path (after)

```
User message (sales read matching isSalesReadIntent)
  → chatRouter: isMigratedReadIntent(SALES) → ASHY
  → fetchChatResponse → POST /api/ashy/chat
  → V2 HTTP handler → get_sales
  → Supabase ventes SELECT (scoped)
  → On failure: SAFE_FALLBACK → n8n (unchanged H4 policy)
```
