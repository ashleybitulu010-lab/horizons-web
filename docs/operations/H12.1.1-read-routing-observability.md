- Correlation IDs linking V2 → fallback → n8n

## 3. Architecture

```
POST /api/ashy/chat (V2)
  → create/reuse X-Ash-Read-Correlation
  → agent.run → v2Http goalType/domain
  → recordV2AshyChatRouting (READ only, skips ACTION)
  → response header X-Ash-Read-Correlation (not in JSON body)

POST /chat (Legacy/n8n)
  → reads X-Ash-Read-Correlation + X-Ash-Read-Fallback
  → isLikelyReadMessage OR safe-fallback header
  → recordLegacyN8nChatRouting (READ_LEGACY | READ_SAFE_FALLBACK)

GET /api/read-routing/metrics (internal key)
  → getReadRoutingMetricsSnapshot()
```

Frontend (`chatTransport.js`) generates correlation id per request, passes it to Ashy and n8n fallback via internal headers only — **not shown in Chat UI**.

## 4. Routing Events

Normalized internal event (logged as `ashy_read_routing`):

```json
{
  "event": "ashy_read_routing",
  "route": "READ",
  "capability": "SALES",
  "primaryPath": "V2_HTTP",
  "outcome": "READ_V2_SUCCESS",
  "fallback": false,
  "latencyMs": 1115,
  "correlationId": "rr-a1b2c3d4e5f6",
  "goalType": "QUESTION",
  "httpStatus": 200,
  "errorCode": null
}
```

**Never logged:** password, Bearer token, API keys, service_role, raw user UUIDs, full user messages.

Files: `apps/api/src/observability/read-routing-observability.js`, `read-capability-inference.js`.

## 5. Metrics

### Global counters

| Counter | Description |
|---------|-------------|
| `READ_TOTAL` | All recorded READ routing events |
| `READ_V2_TOTAL` | V2 success + error |
| `READ_LEGACY_TOTAL` | Direct n8n READ |
| `READ_N8N_FALLBACK_TOTAL` | Safe fallback + legacy n8n |
| `READ_V2_ERROR_TOTAL` | V2 failures |
| `READ_SAFE_FALLBACK_TOTAL` | V2 → n8n fallback |
| `ACTION_TO_N8N_FALLBACK` | Invariant counter (must stay 0) |

### Per capability

SALES, EXPENSES, STOCK, PRODUCTS, DEBTS, PROFIT, REPORT, HISTORY, UNKNOWN — each with outcome sub-counters.

Export: `GET /api/read-routing/metrics` (requires `x-ash-internal-key`).

## 7. Fallback

| Path | Outcome | Instrumented |
|------|---------|--------------|
| V2 success | `READ_V2_SUCCESS` | Yes |
| V2 error | `READ_V2_ERROR` | Yes |
| V2 fail → n8n | `READ_SAFE_FALLBACK` | Yes (via `X-Ash-Read-Fallback: safe-fallback`) |
| Legacy primary n8n | `READ_LEGACY` | Yes |
| ACTION → n8n | **Blocked** | `ACTION_TO_N8N_FALLBACK` incremented, event dropped |

Unit test: `ACTION cannot fallback to n8n — blocked and counted`.

## 16. n8n

Legacy `/chat` proxy records READ events when:

- `isLikelyReadMessage(message)` OR
- `X-Ash-Read-Fallback: safe-fallback`

Does **not** count n8n workflows that exist but are not executed.

Correlation id propagated from V2 attempt on safe fallback.

## 17. Legacy

Global read flag OFF: most non-SALES READs remain Legacy primary.
