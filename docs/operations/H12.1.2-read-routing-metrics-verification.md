## Blocking finding (STOP — no fix applied)

**Production container `ash-ledger-api-v2-ash-ledger-api-1` does not have `ASH_INTERNAL_HEALTH_KEY` set.**

The endpoint implementation is deployed and correct, but `requireInternalHealthKey` returns **503** for every request in production when the variable is absent. This is an **operations/configuration gap**, not a code defect in the metrics handler.

### Required ops action (outside H12.1.2 scope)

1. Add `ASH_INTERNAL_HEALTH_KEY` to the v2 API container environment (same pattern as other internal health endpoints)
2. Re-run `tools/_h1212_read_routing_metrics_gate.mjs`
3. Do **not** commit or log the key value

**No runtime code change was made in H12.1.2 per gate policy.**
