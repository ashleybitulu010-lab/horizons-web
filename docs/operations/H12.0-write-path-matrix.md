**Date:** 2026-09-17

## Expected Primary Path (new Ashy writes)

```
USER → Frontend chatRouter → POST /api/ashy/chat → V2 ACTION PROPOSAL
     → CONFIRM → F4-B2 RPC → Supabase (depenses / ventes + stocks side-effect)
```

**H11 evidence:** ACTION → n8n = **0**.

## Frontend Write Routing (client-side gate)

**File:** `src/lib/chatRouter.js`

| User intent pattern | Route when `VITE_ASHY_WRITE_CHAT=true` | Backend |
|---------------------|----------------------------------------|---------|
| `create_sale`, `create_expense` | **ashy** (V2) | `/api/ashy/chat` |
| Stock receipt, payment, product add, debt, transfer | **n8n** | `/chat` |
| PDF request | **n8n** (always) | `/chat` |
| Pending confirmation (`Oui` / `Non`) | **ashy** | `/api/ashy/chat` |

**Gap:** Most write intents still routed to n8n at frontend level even when V2 ACTIONS ON server-side.

All Supabase writes use `getSupabaseAdmin()` (`SUPABASE_SERVICE_ROLE_KEY`) server-side. Scoped by `client_id` + `activity_id` from authenticated user — **not exposed to browser**.
