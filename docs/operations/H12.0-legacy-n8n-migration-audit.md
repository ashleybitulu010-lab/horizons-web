## 13. Fallback Graph

```
PRIMARY: V2 HTTP (server flags ON)
   │
   ├─ READ success → response (fallbackPolicy=SAFE_FALLBACK available, noN8nFallback=false)
   │
   ├─ READ failure + SAFE_FALLBACK → Frontend may call POST /chat → n8n
   │
   ├─ ACTION → NO_FALLBACK (noN8nFallback=true) → blocked client-side too
   │
   └─ ERROR 500 on /api/ashy/chat → Frontend SAFE_FALLBACK (reads only)
```

| Fallback type | Expected | H11/H12 evidence |
|---------------|----------|------------------|
| READ → n8n | Allowed | Policy OK; smoke used V2 |
| ACTION → n8n | **Forbidden** | **0** |
| ERROR → n8n | Read only | Client policy |
| TIMEOUT → n8n | Read only | Server policy |
| NETWORK → n8n | Read only | Client transport |
