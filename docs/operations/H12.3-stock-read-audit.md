## 1. Current Stock READ path

```
User message (stock read, migrated flags OFF for stock)
  → chatRouter.resolveChatRoute()
  → write guards? → no (for true reads)
  → isMigratedReadIntent(SALES)? → maybe yes
  → isMigratedReadIntent(EXPENSES)? → maybe yes
  → isMigratedReadIntent(STOCK)? → no (not implemented)
  → global read OFF → CHAT_ROUTE.N8N
  → POST /chat → n8n → Supabase stocks SELECT
```

## 2. Target Stock READ path (H12.3)

```
User message (stock read + VITE_ASHY_READ_STOCK=true)
  → chatRouter: write guards first (unchanged)
  → isMigratedReadIntent(STOCK)? → yes
  → CHAT_ROUTE.ASHY
  → fetchChatResponse → POST /api/ashy/chat
  → V2 HTTP → classifyGoal STOCK → get_stock
  → On failure: SAFE_FALLBACK → n8n (unchanged H4 policy)
```

**Backend V2 path already exists:** classifier → plan → `get_stock` → `stock-service.js` → metrics `STOCK.READ_V2_SUCCESS`.

**Blocking gap found:** `selectTemplate()` in `response-templates.js` has no `STOCK` branch — successful reads with data fall through to `templateError()`. H12.3 requires a minimal template fix (allowed by spec).

## 3. Stock READ patterns (planned)

| Pattern | Example |
|---------|---------|
| `^quel(?:le)?s?\s+(?:est\s+)?(?:mon\|mes\|le\|la)\s+stock` | Quel est mon stock ? |
| `^montre(?:-moi)?(?:\s+(?:mon\|mes))?\s+stock` | Montre-moi mon stock |
| `^(?:et\s+)?(?:mes\|les)\s+stocks?\s*\??$` | Quels sont mes stocks ? |
| `^combien\s+(?:me\s+)?reste` | Combien me reste-t-il de poulets ? |
| `reste[- ]?t[- ]?il\s+de` | Il me reste combien de produits ? |
| `quels?\s+produits?\s+(?:me\s+)?restent` | Quels produits me restent ? |
| `(?:mon\|l[''])(?:état\|etat)\s+(?:de\s+)?(?:mon\s+)?stock` | État de mon stock |
| `(?:produits?\s+)?(?:presque\s+)?(?:[é]puis\|stock\s+faible)` | Stock faible / presque épuisé |

**NOT Stock READ (Products — unchanged):**

- `Liste mes produits`
- `Mes produits` (catalogue)

## 4. Stock WRITE / ADJUST patterns (must stay ACTION)

| Pattern | Example | Existing guard |
|---------|---------|----------------|
| `^j['']?ai re[cç]u` | J'ai reçu 10 produits | `WRITE_PREFIX_PATTERNS` / `WRITE_RECEIVED_PATTERN` |
| `^j['']?ai vendu` | J'ai vendu 2 poulets | `isCreateSaleIntent` |
| `\bajoute\b.*\b(stock\|produit\|unit)` | Ajoute 10 poulets au stock | `WRITE_ACTION_PATTERNS` |
| `\b(retire\|enl[eè]ve)\b` | Retire 5 poulets du stock | `WRITE_ACTION_PATTERNS` |
| `\b(corrige\|modifie)\b.*\bstock\b` | Corrige mon stock | `WRITE_ACTION_PATTERNS` |

Evaluation order: **write guards → Sales → Expenses → Stock migrated read → global read**.

---

## 5. READ/WRITE collision risks

| Risk | Mitigation |
|------|------------|
| "Ajoute 10 poulets au stock" as READ | `isWriteIntent` catches `ajoute` before migrated read |
| "J'ai reçu 10 produits" as READ | `WRITE_RECEIVED_PATTERN` (excludes `combien`/`quel` prefix only) |
| "J'ai vendu 2 poulets" as READ | `CREATE_SALE_PREFIX` |
| "Quels produits me restent" vs Products catalog | Specific `restent` pattern; generic product list excluded |
| Activity from message | No clientId/activityId from user text; backend scope unchanged |
