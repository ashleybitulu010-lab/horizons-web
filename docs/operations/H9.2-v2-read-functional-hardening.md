## 4. Root causes

### Issue 1 — Debt → ACTION

| Layer | Cause |
|-------|-------|
| `goal-classifier-rules.js` | DEBTS rule only matched `"qui me doit"` — not `"Quelles dettes clients ?"` |
| `regex-resolver.js` | `parseExpenseFollowUp()` ran before debt patterns; stale expense draft hijacked debt text as expense label |
| Legacy path | With partial draft `{ label, amount }`, `"Quelles dettes clients ?"` → `create_expense` → `ACTION/EXPENSES/CREATE` |

Note: `\bd[eé]penses\b` does **not** match `"dettes"` — the hijack was via expense follow-up, not word confusion.

### Issue 2 — Compare sales → ERROR

| Layer | Cause |
|-------|-------|
| `plan-evidence.js` | Correct: `['sales_period', 'sales_comparison']` |
| `plan-builder.js` | Correct: two `get_sales` steps (current + previous) |
| `plan-executor.js` | Correct: empty sales → step SUCCESS |
| `financial-normalizer.js` | Correct: `noData: true` when count=0 |
| **`financial-analyzer.js`** | **Missing `SALES + COMPARE` branch** → fell through to `UNAVAILABLE` |
| `response-generator.js` | Maps `UNAVAILABLE` → `RESPONSE_STATUS.ERROR` |
| `response-templates.js` | No `templateSalesCompare()`; generic error template used |

## 5. Corrections

### 5.1 Classifier — DEBTS rule expansion

File: `goal-classifier-rules.js`

Added patterns aligned with `GENERIC_DEBT_PATTERNS` from legacy resolver:

- `dettes clients`, `quelles mes dettes`, `combien me doiv`, `montre mes dettes`, etc.
- Guard: exclude messages containing `\bdépenses\b`

### 5.2 Legacy hijack guard

File: `regex-resolver.js`

Added `isDebtRelatedText()` guard in `parseExpenseFollowUp()` (mirrors H7.8 product catalog guard).

### 5.3 Financial analyzer — SALES COMPARE

File: `financial-analyzer.js`

Added `analyzeSalesCompare()`:

- Both periods empty → `FINANCIAL_ANALYSIS_STATUS.NO_DATA`
- Data present → comparison metrics via `compareMetric()`
- Wired in `analyzeFinancialResults()` dispatch

### 5.4 Response templates — SALES COMPARE

File: `response-templates.js`

- Added `templateSalesCompare()` with honest NO_DATA message for empty comparison
- Routed `SALES/COMPARE` and `EXPENSES/COMPARE` **before** generic NO_DATA handler in `selectTemplate()`

### 5.5 Additional hardening (discovered during matrix tests)

| Fix | File | Reason |
|-----|------|--------|
| `isEvolutionCue` plural | goal-classifier-rules.js | `"Comment évoluent mes dépenses ?"` not matched |
| Expenses evolution → COMPARE | goal-classifier-rules.js | Added `isEvolutionCue` to expenses compare rule |
| `J'ai dépensé X dollars pour Y` | goal-classifier-rules.js | Regex did not accept `dollars` word + trailing period |
| `Donne-moi un résumé` → SUMMARIZE | goal-classifier-rules.js | Added to `isGeneralActivitySummaryQuery()` |
