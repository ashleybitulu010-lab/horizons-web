# H12.2 — Expenses READ Migration Audit

**Date:** 2026-09-18  
**Phase:** H12.2 — Second incremental READ migration (Expenses)  
**Prior:** H12.1.2 `H12.1.2_GO_WITH_GAPS` @ `af91830`

---

## 1. Current Expenses READ path

```
User message (expenses read, global read flag OFF)
  → chatRouter.resolveChatRoute()
  → isWriteIntent? → no (for true reads)
  → isMigratedReadIntent(SALES)? → no
  → readFlag OFF → CHAT_ROUTE.N8N
  → POST /chat → n8n → Supabase depenses SELECT
```

---

## 2. Target Expenses READ path (H12.2)

```
User message (expenses read + VITE_ASHY_READ_EXPENSES=true)
  → chatRouter: write guards first (unchanged)
  → isMigratedReadIntent(EXPENSES)? → yes
  → CHAT_ROUTE.ASHY
  → fetchChatResponse → POST /api/ashy/chat
  → V2 HTTP → get_expenses
  → On failure: SAFE_FALLBACK → n8n (unchanged H4 policy)
```

---

## 3. How Sales migration works (reference)

| Layer | Mechanism |
|-------|-----------|
| Detection | `ashyReadMigration.isSalesReadIntent()` — regex list, excludes write openers |
| Flag | `VITE_ASHY_READ_SALES` — default **ON**, `false` = rollback |
| Router hook | After write guards, before global read flag: `isMigratedReadIntent(SALES, text)` |
| Independence | Works when `VITE_ASHY_READ_CHAT=false` |

---

## 4. Expenses detection rules (planned)

### READ (migrate when flag ON)

| Pattern | Example |
|---------|---------|
| `^quelles sont mes dépenses` | Quelles sont mes dépenses ? |
| `^montre(?:-moi)? mes dépenses` | Montre-moi mes dépenses |
| `^combien ai-?je dépensé` | Combien ai-je dépensé ? |
| `^(?:et\s+)?(?:mes\|les)\s+dépenses` | Et mes dépenses ? |

### WRITE (must NOT migrate)

| Pattern | Example | Existing guard |
|---------|---------|----------------|
| `^j'ai dépensé` | J'ai dépensé 30 dollars | `isCreateExpenseIntent` + `WRITE_PREFIX_PATTERNS` |
| `ajoute.*dépense` | Ajoute une dépense de 30 dollars | `isWriteIntent` / `WRITE_ACTION_PATTERNS` |
| `enregistre.*dépense` | Enregistre une dépense | `isWriteIntent` |

Evaluation order in `resolveChatRoute`: **write guards → migrated reads → global read flag**.

---

## 5. Collision risks

| Risk | Mitigation |
|------|------------|
| "J'ai dépensé X" classified as READ | Excluded by `isExpensesWriteOpener()` + write-first router order |
| "Combien ai-je dépensé" vs write | `^combien` excluded from `isCreateExpenseIntent`; READ pattern matches |
| Stock/Products accidental migration | Separate capability flags not enabled |
| Activity from message text | No clientId/activityId from user text; backend scope unchanged |

---

## 6. Rollback

```
VITE_ASHY_READ_EXPENSES=false
→ rebuild/redeploy frontend
→ Expenses reads return to n8n (when global read flag OFF)
```

Sales flag (`VITE_ASHY_READ_SALES`) unchanged.
