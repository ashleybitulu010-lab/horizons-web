# H12.5 — Debts READ Migration Audit

**Date:** 2026-09-18  
**Phase:** H12.5 — Fifth incremental READ migration (Debts)  
**Prior:** H12.4 `H12.4_GO_WITH_GAPS` @ `596ae93`

---

## 1. Current Debts READ path

```
User message (debts read, VITE_ASHY_READ_DEBTS unset/false)
  → chatRouter.resolveChatRoute()
  → write guards? → no (for true reads; payment writes partially guarded)
  → isMigratedReadIntent(SALES|EXPENSES|STOCK|PRODUCTS)? → maybe yes
  → isMigratedReadIntent(DEBTS)? → no (not implemented)
  → global read OFF → CHAT_ROUTE.N8N
  → POST /chat → n8n → ventes (reste_a_payer) / legacy debt flow
```

**Note:** Direct `/api/ashy/chat` already classifies debt queries as DEBTS RETRIEVE and executes `get_debts`, but V2 HTTP response falls through to `templateError()` (no DEBTS template branch).

---

## 2. Target Debts READ path (H12.5)

```
User message (debts read + VITE_ASHY_READ_DEBTS=true)
  → chatRouter: write guards first
  → prior migrated reads unchanged
  → isMigratedReadIntent(DEBTS)? → yes
  → CHAT_ROUTE.ASHY → POST /api/ashy/chat
  → classifyGoal DEBTS RETRIEVE → get_debts
  → templateDebtsRetrieve → metrics DEBTS.READ_V2_SUCCESS
```

## 3. Backend V2 data (`get_debts`)

Source: `debts-service.js` — reads `ventes` scoped by `client_id` + `activity_id`.

| Field | Supported |
|-------|-----------|
| Unpaid debt list | ✓ (`status: unpaid`, `reste_a_payer > 0`) |
| Total remaining | ✓ `summary.totalRemaining` |
| Unpaid count | ✓ `summary.unpaidCount` |
| Debtor count | ✓ `summary.debtorCount` |
| Paid amount per row | ✓ `paid` |
| Remaining per row | ✓ `remaining` |
| Debtor filter by name | ✓ `input.debtor` (business label match) |

**Not invented:** cross-activity totals, payment history list (`paiements_dettes` table not queried by `get_debts`).

## 4. Debts READ patterns (planned frontend)

Aligned with backend classifier rule (~line 1094):

| Pattern | Example |
|---------|---------|
| `^quelles? … dettes` | Quelles sont mes dettes ? |
| `^montre … dettes` | Montre-moi mes dettes |
| `^mes dettes` / `^(?:et\s+)?(?:mes\|les) dettes` | Mes dettes ? |
| `qui me doit` | Qui me doit de l'argent ? |
| `combien.*me doiv` / `combien me doit` | Combien me doit-on ? |
| `dettes? clients?` | Dettes clients |
| `clients? débiteurs` / `liste.*débiteurs` | Liste des débiteurs |
| `total.*dettes` | Quel est le total de mes dettes ? |

**Exclusion:** `\bdépenses?\b` (backend parity).

## 5. Debts WRITE / payment patterns (must stay ACTION/Legacy)

| Pattern | Example | Guard |
|---------|---------|-------|
| `^ajoute.*dette` | Ajoute une dette de 50 $ | `isWriteIntent` |
| `^crée.*dette` | Crée une dette | `isWriteIntent` |
| `^enregistre.*paiement` | Enregistre le paiement | `isWriteIntent` |
| `^j'ai payé.*dette` | J'ai payé 30 $ de ma dette | **H12.5 `isDebtsWriteOpener`** (gap in `isWriteIntent`) |
| `^modifie.*dette` / `^supprime.*dette` | Modifie la dette du client | `isWriteIntent` |
| `^un client me doit` | Un client me doit 50 $ (create) | `WRITE_PREFIX_PATTERNS` |

Order: **write guards → Sales → Expenses → Stock → Products → Debts → global read → n8n**.

## 6. Ambiguous cases (Phase 4 decisions)

| Message | V2 classifier | H12.5 routing | Decision |
|---------|---------------|---------------|----------|
| Quelles sont mes dettes ? | DEBTS RETRIEVE | V2 when flag ON | **Migrated** |
| Qui me doit de l'argent ? | DEBTS RETRIEVE | V2 | **Migrated** |
| Combien me doit-on ? | DEBTS RETRIEVE | V2 | **Migrated** |
| Donne-moi la liste des débiteurs | null (gap) | V2 after classifier fix | **Migrated after minimal rule** |
| Combien ai-je payé ? | null | Legacy/n8n | **Gap — ambiguous (debts vs sales)** |
| Mes paiements | null | Legacy/n8n | **Gap — payment history not in get_debts** |
| Combien reste-t-il à payer ? | null | Legacy/n8n | **Gap — ambiguous without debt context** |
| Ma dette / Dette du poulet | null | Legacy/n8n | **Gap — insufficient context** |
| J'ai payé 30 $ de ma dette | not DEBTS READ | n8n/ACTION | **Write — blocked by opener** |

## 7. Multi-turn context (Phase 5)
