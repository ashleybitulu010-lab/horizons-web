# H12.4 — Products READ Migration Audit

**Date:** 2026-09-18  
**Phase:** H12.4 — Fourth incremental READ migration (Products catalog)  
**Prior:** H12.3 `H12.3_GO` @ `406d744`

---

## 1. Current Products READ path

```
User message (products catalog read, VITE_ASHY_READ_PRODUCTS unset/false)
  → chatRouter.resolveChatRoute()
  → write guards? → no (for true reads)
  → isMigratedReadIntent(SALES)? → maybe yes
  → isMigratedReadIntent(EXPENSES)? → maybe yes
  → isMigratedReadIntent(STOCK)? → maybe yes (catalog queries excluded in isStockReadIntent)
  → isMigratedReadIntent(PRODUCTS)? → no (not implemented)
  → global read OFF → CHAT_ROUTE.N8N
  → POST /chat → n8n → Supabase produits SELECT
```

**Note:** Direct API calls to `/api/ashy/chat` already succeed for catalog reads (verified H12.3 gate: `Liste mes produits` → PRODUCTS SUCCESS). Only frontend routing is missing.

---

## 2. Target Products READ path (H12.4)

```
User message (catalog read + VITE_ASHY_READ_PRODUCTS=true)
  → chatRouter: write guards first (unchanged)
  → isMigratedReadIntent(SALES|EXPENSES|STOCK)? → unchanged
  → isMigratedReadIntent(PRODUCTS)? → yes
  → CHAT_ROUTE.ASHY
  → fetchChatResponse → POST /api/ashy/chat
  → V2 HTTP → classifyGoal PRODUCTS RETRIEVE → get_products
  → On failure: SAFE_FALLBACK → n8n (unchanged H4 policy)
```

**Backend V2 path already exists:** `isProductCatalogReadQuery()` → plan `products_catalog` → `get_products` → `templateProductsRetrieve()` → metrics `PRODUCTS.READ_V2_SUCCESS`.

**No blocking backend gap** for catalog list reads.

## 3. Products READ patterns (planned frontend)

Aligned with backend `isProductCatalogReadQuery()`:

| Pattern | Example |
|---------|---------|
| `^(?:quels?\|liste…\|montre…\|donne…\|affiche).*(?:mes\s+)?produits` | Liste mes produits |
| `^mes produits` | Mes produits ? |
| `(?:quels?\|liste).*(?:mes\s+)?produits\s*\??$` | Quels sont mes produits ? |
| `mon catalogue` | Mon catalogue |
| `mes articles` | Mes articles |
| `quels produits (?:ai-je\|je vends\|sont enregistr)` | Quels produits ai-je ? |
| `\bcombien de produits\b` (no `reste`) | Combien de produits ai-je ? |

**Exclusion regex (catalog vs stock/sales):** `vendu|vente|dépens|bénéf|stock|reste|épuis|mieux|plus vendu|presque`

## 4. Products WRITE patterns (must stay ACTION / Legacy)

| Pattern | Example | Guard |
|---------|---------|-------|
| `^ajoute.*produit` | Ajoute un produit | `isWriteIntent` |
| `^crée.*produit` | Crée un produit | `isWriteIntent` |
| `^enregistre.*produit` | Enregistre un nouveau produit | `isWriteIntent` |
| `modifie.*produit` / `modifie.*prix` | Modifie le prix du poulet | `isWriteIntent` |
| `supprime.*produit` / `retire.*produit` | Supprime le produit poulet | `isWriteIntent` |
| `^modifie le produit X` | Modifie le produit Savon | Backend `parseProductWriteAction` → ACTION |

Evaluation order: **write guards → Sales → Expenses → Stock → Products migrated read → global read → n8n**.

---

## 5. READ/WRITE collision risks

| Risk | Mitigation |
|------|------------|
| "Ajoute un produit" as Products READ | `isWriteIntent` before migrated read |
| "Modifie le prix du poulet" as Products READ | `isWriteIntent` (`modifie`) before migrated read |
| "Liste mes produits" as Stock READ | H12.3 exclusion in `isStockReadIntent`; Products hook after Stock |
| "Quels produits me restent ?" as Products READ | STOCK pattern + catalog exclusion (`reste`) |
| "Combien me reste-t-il de poulets ?" as Products READ | STOCK pattern; not catalog |
| "Meilleur produit" / ranking | Backend PRODUCTS with `ranking: best_seller`; not in H12.4 catalog patterns |
| Activity from message | No clientId/activityId from user text; backend scope unchanged |

---

## 6. Ambiguous cases (Phase 3 decisions)

| Message | V2 classifier (rules) | H12.4 frontend routing | Decision |
|---------|----------------------|------------------------|----------|
| Liste mes produits | PRODUCTS RETRIEVE | V2 when flag ON | **Migrated** |
| Quel est le prix du poulet ? | `null` (no rule) | Legacy/n8n | **Gap — not migrated** |
| Combien coûte mon poulet ? | `null` | Legacy/n8n | **Gap — not migrated** |
| Montre-moi le poulet | `null` | Legacy/n8n | **Gap — not migrated** |
| Donne-moi les informations du poulet | `null` | Legacy/n8n | **Gap — not migrated** |
| Combien me reste-t-il de poulets ? | STOCK RETRIEVE | STOCK V2 (H12.3) | **Stock, not Products** |
| Change le prix du produit | `null` | n8n (not write guard) | **Not Products READ; stays Legacy** |

Price/single-product detail queries require new classifier rules + template — **out of H12.4 scope** unless blocking (they are not).

## 7. Activity / scope model

```
authenticated user → client_id → activity_id (header / session)
```

Backend `get_products` scopes by `client_id` + `activity_id`. Foreign activity → HTTP 403 (verified H12.1–H12.3 pattern).
