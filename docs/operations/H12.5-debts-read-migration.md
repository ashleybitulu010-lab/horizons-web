## 3. Avant / après routing

**Avant (flag OFF):**
```
"Quelles sont mes dettes ?" → write guards → n8n (Legacy)
```

**Après (VITE_ASHY_READ_DEBTS=true):**
```
"Quelles sont mes dettes ?" → write guards → isMigratedReadIntent(DEBTS) → ASHY → V2 HTTP
```

Ordre : WRITE guards → Sales → Expenses → Stock → Products → **Debts** → global read → n8n.
